# Changelog

## Current Features

- **Layer-Based Editing**: Create and manage layers for text, headshots, and backgrounds.
- **Draggable and Resizable Layers**: Manipulate layers by dragging and resizing them.
- **Text Styling**: Customize text layers with options for font size, color, bold, italic, and underline.
- **Headshot Styling**: Customize headshot layers with options for shape (circle/square), border, and corner radius.
- **Export to HTML**: Export the final design as a complete HTML file.
- **Dark Mode**: Switch between light and dark themes for a comfortable user experience.
- **Undo/Redo**: Easily undo and redo actions.

## New Features

- **Canvas Size Dropdown**: A new dropdown in the header allows you to change the canvas size.
  - **Current**: Reverts to the default canvas size (1200x720).
  - **1200x1200**: Sets the canvas to a square 1200x1200 dimension.
  - **Custom**: Opens a modal to input a custom width and height for the canvas.
